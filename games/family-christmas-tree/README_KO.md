# 우리 가족의 크리스마스트리

가현 · 지용 · 영현 · 토토와 함께 꾸미는 작은 3D 거실입니다.
시간 제한, 로그인, 결제, 외부 서버 연결이 없습니다. 소리는 사용하지 않습니다.

## 가장 쉬운 실행 — Windows

1. **`FamilyChristmasTree-LivingRoom.exe`를 두 번 클릭**합니다.
2. 기본 브라우저에 게임이 열립니다. 자동으로 열리지 않으면 `http://127.0.0.1:8765/`에 접속하세요.
3. **꾸미기 시작**을 누릅니다.
4. 게임을 마치면 게임 실행 창을 닫습니다.

실행 파일에 게임과 모든 에셋이 들어 있습니다. 플레이할 때 Node.js, Blender, 인터넷이 필요하지 않습니다.
Windows의 .NET Framework 4.x와 WebGL 2를 지원하는 Chrome/Edge가 필요합니다.
검증 PC에서는 Windows 실행 파일을 직접 실행하고 Edge에서 실제 게임을 조작했습니다.
`start-windows.bat`으로도 실행할 수 있습니다.

실행 중인 게임 창이 있는데 다시 실행하면 포트 사용 안내가 표시됩니다. 기존 브라우저 탭을 사용하세요.
실행 파일은 웹 파일을 사용자 로컬 앱 데이터의 `FamilyChristmasTree/web-v1` 폴더에 풉니다.
장식 기록은 파일이 아니라 **브라우저의 localStorage**에 저장됩니다.

## 거실 배경 꾸미기

- 트리 아래에는 리본 선물 7개가 두 더미와 앞쪽 상자로 쌓여 있습니다.
- 왼쪽 벽난로 위 시계는 기기의 현재 시간에 맞춰 시침·분침·초침이 움직입니다.
- 게임을 열어 두고 낮 12시 또는 밤 12시를 지나면 산타가 굴뚝을 내려와 인사합니다.
- **벽난로와 산타 → 산타 미리보기**로 언제든 다시 볼 수 있습니다. 산타는 약 11초 동안 나타납니다.
- 동작 줄이기 설정에서는 내려오는 동작 대신 산타의 인사를 보여 줍니다.

- **거실 배경 꾸미기**에서 벽지·바닥·러그 색상을 고릅니다.
- 소파·벽 리스·벽 전구·가족 액자·스탠드 조명 버튼으로 장식을 보이거나 숨깁니다.
- 배경도 자동 저장되며 되돌리기와 완성 사진에 반영됩니다.
- 이전 버전에서 꾸민 트리는 그대로 불러옵니다.
- 이전 실행 창이 열려 있으면 닫은 뒤 새 거실 버전을 실행하세요.

## 꾸미는 방법

- 오른쪽(휴대폰에서는 아래)의 장식 버튼을 고릅니다.
- 트리에 나타나는 **금빛 점**을 누르면 장식이 달립니다. 별은 꼭대기 전용 점에 달립니다.
- 마우스 드래그 또는 한 손가락으로 장면을 회전합니다. 휠·두 손가락 또는 ＋/− 버튼으로 확대합니다.
- 이미 달린 장식을 누르면 색상을 바꾸거나 삭제할 수 있습니다.
- **되돌리기 / 다시하기**는 최근 100번의 변경까지 지원합니다. 초기화도 되돌릴 수 있습니다.
- 전구 스위치를 켜고, 따뜻한 흰색 또는 여러 색을 선택합니다. 빠르게 깜빡이는 효과는 없습니다.
- 가현·지용·영현·토토를 누르거나 아래 이름 버튼을 누르면 인사합니다.
- 장식 8개와 별을 달면 불 켜기 목표를 안내합니다. 목표 전후에도 자유롭게 꾸밀 수 있습니다.
- **완성 사진 → PNG 사진 저장**으로 UI가 없는 1800×1200 사진을 저장합니다.
- 모바일에서 다운로드가 지원되지 않으면 사진 미리보기를 길게 눌러 저장하세요.

### 키보드

Tab으로 장식·색상·버튼을 이동하고 Enter 또는 Space로 선택합니다.
**키보드로 장식 달기**를 펼쳐 장착 위치를 선택한 뒤 **선택한 위치에 달기**를 누릅니다.
위치를 바꾸면 그 면으로 카메라가 이동합니다. Ctrl+Z는 되돌리기, Ctrl+Shift+Z는 다시하기입니다.
선택된 장식은 Delete 키로 지울 수 있습니다.

### 자동 저장

장식 배치·색상·전구·거실 배경 설정은 변경할 때마다 저장됩니다. 같은 브라우저·같은 주소에서 다시 열면 복구됩니다.
시크릿 모드, 브라우저 데이터 삭제, 다른 브라우저·PC·휴대폰에는 기록이 공유되지 않습니다.
기록이 손상되면 새 트리로 시작하며, 저장 공간 쓰기가 막혀도 현재 게임은 계속됩니다.
되돌리기 이력은 현재 방문에서만 유지됩니다.

## 휴대폰 — 같은 Wi-Fi

1. PC의 기존 게임 실행 창을 닫고 **`start-phone.bat`**을 실행합니다.
2. 실행 창에 나온 `http://PC의사설IP:8765/` 주소를 휴대폰에서 엽니다.
3. 방화벽 안내가 나타나면 필요할 때 **개인 네트워크만** 허용하세요.

기본 실행은 이 PC에서만 접속할 수 있습니다. 휴대폰 모드는 사용자가 실행했을 때만 로컬 네트워크 접속을 엽니다.
공유기 포트 개방이나 인터넷 공개 배포는 하지 않습니다. 실제 휴대폰 기기의 성능·Wi-Fi 접속은 미검증입니다.
360px 모바일 화면, 터치 입력과 일반 HTTP 환경의 ID 생성 대안은 Edge 자동 검증으로 확인했습니다.

## 캐릭터의 표현 범위

네 캐릭터는 사진을 평면에 붙인 것이 아니라 **실제 입체 메시**입니다.
가현의 앞머리·빨간 니트·밝은 바지, 지용의 짧은 머리·초록 니트,
영현의 긴 머리·아이보리 니트·빨간 목도리, 토토의 크림색 몸·처진 귀·빨간 스카프를 반영했습니다.

**얼굴과 체형의 닮은 정도는 스타일화 초안 수준**이며 사진처럼 동일하지 않습니다.
한 장의 사진에 보이지 않는 뒷모습은 추정 제작했습니다.
몸·팔·꼬리의 계층 애니메이션을 사용하며, 본 리깅이나 실제 털 시뮬레이션은 사용하지 않습니다.
인물 GLB에는 Idle·Celebrate, 토토 GLB에는 Idle·TailWag 클립이 들어 있습니다.

원본 가족사진·토토 사진은 이 전달 폴더나 실행 파일에 포함하지 않았습니다.
외부 이미지→3D 서비스에 업로드하지 않았고, 유료 서비스나 공개 배포도 사용하지 않았습니다.

## 개발·재현

개발 시 Node.js 22.12 이상 또는 24 이상을 권장합니다. 패키지 버전은 lockfile에 고정되어 있습니다.

최초 한 번:

```powershell
npm ci
```

이후 개발 실행:

```powershell
npm run dev -- --port 5173 --strictPort
```

빌드와 상태 테스트:

```powershell
npm test
npm run build
powershell -File launcher/build-windows.ps1
```

Blender 5.2.2 LTS에서 검증한 에셋 재생성:

```powershell
& '설치된 Blender 실행 파일 경로' --background --factory-startup --python asset-source/generate_assets.py
```

특정 에셋만 재생성하려면 끝에 `-- gahyun toto`처럼 ID를 추가합니다.
재생성은 해당 에셋을 덮어쓰므로 수작업으로 수정한 원본은 먼저 별도 복사하세요.
단위는 미터, Blender Z-up에서 GLB Y-up으로 한 번 변환합니다. 텍스처 파일 없이 표준 PBR 재질을 사용합니다.

브라우저 검증에는 Playwright를 별도 설치하거나 `PLAYWRIGHT_MODULE` 환경 변수로 경로를 지정한 후:

```powershell
$env:GAME_URL='http://127.0.0.1:8765'
node tests/browser-acceptance.cjs
```

패키지는 [Three.js](https://threejs.org/)와 [Vite](https://vite.dev/)를 사용합니다.
라이선스는 `THIRD_PARTY_NOTICES.md`를 참고하세요.
